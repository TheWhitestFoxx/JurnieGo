# JurnieGo

Fun interactive learning game for kids ages 4–7 starring Jurnie, Fancy the cat, and Leah.

## Features
- Name entry + spelling practice
- Letter tracing (upper & lower case)
- Number tracing 0–20
- Shapes, Emotions, Animals, Colors
- Counting challenges
- Matching memory game
- Cozy house with 9 doors to explore

## How to Play
Open index.html in any modern browser (phone, tablet, or computer).

Made with love for little learners.
